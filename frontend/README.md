# VoiceLocal 🎙️🌏

**One Video. Every Voice.**

VoiceLocal is an AI-powered video localization platform designed to help creators, educators, businesses, NGOs, and publishers reach India's multilingual audience.

## ✨ Features

- 🎤 Speech-to-text transcription
- 🌐 AI-powered translation
- 🔊 Natural AI voice dubbing
- 📝 Subtitle generation
- 🎬 Localized video export
- 🗣️ Multi-language voice previews
- 🇮🇳 Support for India's official languages + English
- 🔐 JWT-based authentication
- 📊 Project history and analytics
- ♿ Accessibility-focused UI with screen-reader support

## 🏗️ Architecture

### Frontend
- React
- JavaScript
- Tailwind CSS
- shadcn/ui
- Recharts
- Framer Motion

### Backend
- FastAPI
- MongoDB
- Motor
- JWT authentication
- AI translation and text-to-speech services
- FFmpeg for media processing
